# 5.7 同人创作 · 归来的曙光

这是保留的早期同人续写，使用原有Boss（包含暗黑王子）和文字剧情串联三场战斗。它与源码重建续写 **6.0《归光之约》** 是两个不同实现；5.7和6.0均为本项目的同人版本号，原版基线仍为5.6。

| 文件 | 用途 |
|---|---|
| `story.json` | 旧版三场战斗、对白与结局数据 |
| `src/Epilogue.as` | 加载原游戏核心、旧章节界面/战斗控制、5.7首页公告 |
| `generate_story.py` | 将故事数据生成编译输入 |
| `build.sh` | 编译根目录的旧 `终章入口.swf` |
| `../终章核心.swf` | 旧入口加载的隔离核心，保存名为 `yzlr2_final` |
| `../tools/prepare_epilogue.py` | 核验原文件并准备旧核心；首次运行可能准备旧版存档，不能当作新版启动器 |

当前正式同人快捷方式运行 **6.0**，不运行此入口。5.7保留为历史实现，不新增第四个正式快捷方式。未改名之前的历史快照仍为 `final-chapter-v1-before-v2-20261025`，不会改写该引用。

2026-10-26：应用户要求，旧入口首页显示“5.7 同人创作”，并明确复用旧Boss；新版首页显示“6.0 同人创作”，其“历史版本”按钮在游戏内展示5.6/5.7/6.0沿革。两处均只改变展示版本号，不改变原存档迁移字段 `Main.varX=560`，也不更换保存文件名。原版权说明保留。
