# 司灯遗址的两组镜盘

开发构建 `runtime-all-rebuilt-20261113T072158.633060Z` 将装置修复改为玩家可以操作的镜盘。灯塔需要接通求援和回信，解缚环需要同时托住内扣和外扣。两面板分别绘制光源、可转动的五面镜子与两个同色接收口。鼠标点击右侧按钮或按数字 1—5 可以转镜；两条光路接通后可确认。装置仍各自带来原本的终战援助与结局选项。

本轮启用同一独立毕业起点，从村庄、码头、暗道浮桥走到司灯，击败司灯后从地图里的装置进入镜盘。灯塔初始两路均断开。求援接通、回信断开时点击修复按钮，实机仍显示未修复。完全退出并重开，再从同一角色进入灯塔，求援一束亮、回信一束暗，镜面方向与退出前相同。完成第二束并确认后，灯塔修复。右边的解缚环保留自己的初始状态，调整内外两路并确认后也完成修复。两台均修好后可正常进入王座。

完整包严格重建 164 个模块，零原 ABC 回退。与正式版相比只有 Main 的 SWF 字节变化。两种镜盘各 32 种配置中都只有一种能同时接通两路，十种仅接通一路。原始窗口截图和只读存档检查在开发工作树的 `chapter/evidence/private/candidate20/`。这个测量范围仅覆盖在本文中实际操作的路径。

毕业测试角色完成两种装置后，击败王座、通过三节点仪式、回村听到「万家之火」后日谈。导师首屏至回村后日谈的墙钟间隔为 310.5 秒，含冷读和取证停顿。该路线仍短于 20 分钟。可复核的摘要见[镜盘实测数据](../evidence/candidate20-mirrors.json)。
