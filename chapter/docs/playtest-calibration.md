# 正常测试档与战斗节奏基准

这是合成的“原数值中等装备终章起点测试档”，不是自然成长通关实录。角色85级、50级玄冰四件与金剑/杖，六件均+10，无宝石/祝福；固定装备属性倍率1。毕业槽固定属性倍率10，强化同样+10。例如甲生命881对8810，剑攻击282对2820。旧源码重建验收HP48848来自毕业预设，不能把它当本章普通档的血量下限。正常槽实际HP18627、基础攻击2017.2、防御760.15，战斗buff会改变攻击值。

原二星Enemy71奥加：Data2_data.as中HP330万；六招基础伤害8888/4000/6000/6000/6000/8000，部分多次命中。新司灯42万HP、基础攻击1800、每个危险对象一次伤害；不能因此声称二者难度等价，因为被动、技能与机制不同。

原帧率27fps。依据Skin_player0时间轴标签：剑技1约0.704秒、技2约1.481秒、技3约1.333秒、技4约1.704秒；转职最长约1.889秒。多数长技不能中断，技能中按方向键可能不立即移动。司灯恢复1.35秒加第一阶段预警1.35秒，共2.7秒；恢复开始放长技后仍有约0.81秒反应窗口。预警已出现时不宜新起长动作。紫色光锚要横移，跳跃不能躲；地波须等逼近再跳，太早起跳会落回波上。
